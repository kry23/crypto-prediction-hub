## Key v0.2 findings

- **Incremental ingest works in practice**: 22 minutes wall-clock to fetch ~286k missing bars across 340 symbols × 4 timeframes after a 21h gap. Reasonable for the 06:15 → 06:30 window. For routine 24h-stale ingests, expected to run in 1-2 minutes.
- **Sentiment fetcher needs NewsAPI key in secrets.env** — currently `NEWSAPI_API_KEY` slot exists but unfilled in production; without it the sentiment fetcher silently skips and the cache stays empty (graceful fallback).
- **Global fetcher works against CoinGecko free tier** — no API key required; rate limit ~30 req/min plenty for daily snapshot.
- **Drift detection threshold 0.05 above backtest baseline 0.226** — chosen conservatively. After 30+ days of live data, this should be re-tuned against observed variance.

After v0.2 ships, the system is production-ready:
